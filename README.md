# ClockBridge Deploy

Download the ClockBridge beta installers here.

## Get started

1. **Join the Discord** to engage with other users and get your beta activation key: https://discord.gg/NZ8Emjdwz
2. **Download the app** from the [latest release](../../releases/latest):

| Platform | Server | User |
|----------|--------|------|
| macOS | `ClockBridgeServer-mac.pkg` | `ClockBridgeUser-mac.pkg` |
| Windows | `ClockBridgeServer-windows.exe` | `ClockBridgeUser-windows.exe` |

Bitfocus Companion: `companion-module-clockbridge.tgz`

Only the Server app needs an activation key. The User app and the Companion module don't.

The installers are not code-signed, so macOS Gatekeeper or Windows SmartScreen may warn on first launch. See the setup guide for how to proceed.

This repository only hosts release downloads. It contains no source code.
